# Machine Learning for Cyber Security

A collection of machine learning experiments focused on solving cybersecurity problems using statistical analysis and machine learning techniques.

**Course:** Machine Learning for Cyber Security  
**Course Code:** 25MCAIS302

---

## About

This repository contains six practical experiments covering time-series analysis, DDoS traffic forecasting, cyber-attack classification, and malicious URL detection.

The experiments demonstrate the application of different machine learning algorithms to cybersecurity datasets and include data preprocessing, model implementation, visualization, and performance evaluation.

---

## Experiments

| # | Experiment | Technique |
|---|---|---|
| 01 | Time Series Decomposition | Time Series Analysis |
| 02 | Historical Network Traffic Forecasting for Potential DDoS Attacks | ARIMA |
| 03 | Cyber-Attack Classification | Random Forest |
| 04 | Legitimate and Malicious URL Classification | Logistic Regression |
| 05 | Legitimate and Malicious URL Classification | SVM |
| 06 | Logistic Regression vs SVM for URL Classification | Model Comparison |
