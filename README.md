# Machine Learning for Cyber Security

A collection of machine learning experiments focused on solving cybersecurity problems using statistical analysis and machine learning techniques.

**Course:** Machine Learning for Cyber Security  
**Course Code:** 25MCAIS302

---

## About

About

This repository contains twelve practical experiments covering various areas of cybersecurity using statistical analysis, machine learning, and data-driven techniques.

The experiments include time-series analysis, DDoS traffic forecasting, cyber-attack classification, malicious URL detection, CAPTCHA detection, email spoofing, mail classification, network event classification, injection detection, and malicious wireless sensor network detection.

The experiments demonstrate data preprocessing, model implementation, visualization, classification, prediction, and performance evaluation.
